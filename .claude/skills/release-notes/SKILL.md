# Release notes үүсгэгч (монголоор)

git түүхээс хэрэглэгчдэд зориулсан, цэвэр монгол хэлээр бичсэн хувилбарын тэмдэглэл гаргана.

## Алхмууд
1. Хамрах хүрээг тодорхойл:
   - Сүүлийн tag-аас хойш: `git describe --tags --abbrev=0` → `git log <tag>..HEAD --oneline`
   - Tag байхгүй бол: `git log --oneline -30` эсвэл хэрэглэгчээс хугацааг асуу.
2. Commit-уудыг уншиж, **техникийн биш**, хэрэглэгчид ойлгомжтой хэлээр хөрвүүл.
3. Дараах ангилалд хувааж бич (хоосон ангиллыг алгасна):
   - 🎤 **Шинэ боломж**
   - 🐛 **Засвар**
   - ⚡ **Сайжруулалт**
   - 🧹 **Бусад / дотоод**
4. Тал бүрийг богино өгүүлбэрээр, "хэрэглэгч юу мэдрэх вэ" өнцгөөс бич.
5. Эхэнд хувилбар/огноо толгой нэм (ж: `## v1.1 — 2026-06-07`).

## Гаралтын загвар
```markdown
## v1.1 — 2026-06-07

🎤 **Шинэ боломж**
- Япон хэл рүү орчуулах сонголт нэмэгдлээ.

🐛 **Засвар**
- Микрофон зарим утсан дээр зогсдог асуудлыг зассан.

⚡ **Сайжруулалт**
- Яриа таних хурд нэмэгдэж, токен тоолуур нарийвчлагдсан.
```

## Зөвлөмж
- Энэ төсөл хэрэглэгчид монголоор ярьдаг тул **бүх тэмдэглэлийг монголоор** бич.
- "refactor", "chore" зэрэг дотоод commit-уудыг "Бусад"-д товчхон оруул эсвэл орхи.
- Commit мессеж тодорхойгүй бол өөрчлөгдсөн файлуудыг (`git show --stat`) хараад утгыг нь тодорхойл.
- Бэлэн болсон тэмдэглэлийг `CHANGELOG.md`-д нэмэхийг санал болго (зөвшөөрснөөр).
